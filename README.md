# 🐱🐶 Cat vs Dog Image Classification

This project implements an image classifier to distinguish between cats and dogs using Keras in a Google Colab environment.

---

## 📁 Project Structure

- `cat-dog-classification.ipynb`: Main notebook for data preprocessing, model training, evaluation, and prediction.
- **Dataset**: [Dogs vs Cats by salader on Kaggle](https://www.kaggle.com/datasets/salader/dogs-vs-cats)

---

## 🧪 Features

- Data loading and preprocessing
- Real-time data augmentation
- CNN training with live metrics display
- Model evaluation on test data
- Prediction and visualization of results

---

## ▶️ How to Run

1. Open the notebook in Google Colab:  
   `cat-dog-classification.ipynb`

2. Upload the dataset or link to Google Drive / use Kaggle API.

3. Run all cells sequentially:
   - Preprocessing
   - Model creation
   - Training
   - Evaluation
   - Predictions

---

## 📊 Results

- Training and validation accuracy/loss plots
- Model achieves high accuracy on the validation set (typically ~90%+ depending on dataset size and training time)

---

## 📌 Notes

- For large datasets, use Colab’s GPU support for faster training.
- Ensure proper train/validation/test splits to avoid overfitting.
- You can further improve results.
